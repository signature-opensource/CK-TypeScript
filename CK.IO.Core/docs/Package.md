Serializable data: [`ICKExceptionData`](https://github.com/signature-opensource/CK-TypeScript/blob/stable/CK.IO.Core/ICKExceptionData.cs),
the `IPoco` representation of an exception (message, type names, stack trace, inner and aggregated exceptions), and the
[`LogLevel`](https://github.com/signature-opensource/CK-TypeScript/blob/stable/CK.IO.Core/LogLevel.cs) flags enum
(`Debug`, `Trace`, `Info`, `Warn`, `Error`, `Fatal`, and the `IsFiltered` flag).
See the [README](https://github.com/signature-opensource/CK-TypeScript/blob/stable/CK.IO.Core/README.md).
